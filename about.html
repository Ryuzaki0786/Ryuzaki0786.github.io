01 / About

I'd rather understand one layer completely than skim five.

Background

I'm a Computer Engineering undergraduate at Purdue University, concentrating in Software Engineering and AI/ML. I'm also taking coursework in computer systems (architecture, compilers, operating systems) because I like knowing what's actually happening underneath the tools I use.

I learn best by building things instead of just reading about them. I wrote a Unix shell using raw system calls instead of a shell library, a TCP server using raw sockets, and a simulation engine where I worked out the linear algebra by hand before writing any code. It's slower, but it's the only way things actually stick for me.

Most of my projects start the same way. I run into a question I can't answer just by looking at a diagram, like what a kernel actually does with a signal, or where a GPU stops being fast, so I build the answer instead.
