quantum-sim
C++ / CUDA
2026

A quantum circuit simulator, written from zero

A numerical simulation engine with no external math dependencies — templated linear algebra, an RK4 integrator validated against damped harmonic oscillators, and finite-difference PDE solvers for the wave and heat equations. Extended into full state-vector circuit simulation. The CUDA path keeps state resident on device across gate application rather than round-tripping to host memory, which is where the speedup actually comes from.

esh
C / POSIX
2025

A Unix shell — fork, exec, pipes, signals

A working shell built directly on system calls. Command parsing, foreground and background job control, pipelines between processes, signal handling for SIGINT and SIGTSTP, and I/O redirection. Written to find out precisely what happens between pressing Enter and seeing output — and how much of that a library normally hides.

chatserver
C / TCP
2025

A multi-client TCP chat server on raw sockets

A concurrent server handling many simultaneous clients over TCP using select-based I/O multiplexing — one thread, no blocking, no framework. Socket lifecycle management, per-client state tracking, and message broadcast. Written to understand the network stack that sits under every web framework I will ever be handed.
